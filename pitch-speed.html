MLB Pitch Speed Analysis

Exploring how historical pitch velocity and game context can inform expectations for future pitches.

Baseball SavantStatcastPitch-level analysis

Project overview

Pitch velocity varies across pitchers and game situations. This project examines historical pitch-level observations to identify relevant tendencies and evaluate velocity thresholds in context.

Variables considered

  • Pitcher tendencies and historical velocity
  • Batter handedness and ball-strike count
  • Inning, pitch sequence and prior game performance

Analysis workflow

01 / Data

Collect

Review historical pitch-level observations from Baseball Savant.

02 / Context

Compare

Examine comparable situations, pitcher tendencies and prior velocity observations.

03 / Evaluation

Interpret

Assess historical velocity patterns relative to a selected threshold.
